# Weekly Business Performance Dashboard

## Deskripsi

Project ini merupakan dashboard laporan bisnis mingguan yang dibuat menggunakan Tableau Public dan ditampilkan melalui halaman HTML menggunakan iframe.

Dashboard digunakan untuk memantau performa bisnis mingguan secara visual dan interaktif.

---

## Fitur Dashboard

- Visualisasi performa bisnis mingguan
- Dashboard interaktif berbasis Tableau Public
- Tampilan fullscreen menggunakan iframe
- Mudah diakses melalui browser

---

## Teknologi yang Digunakan

- HTML5
- Microsoft Excel
- Tableau Public

---


---

## Cara Menjalankan

1. Clone repository:

```bash
git clone https://github.com/username/weekly-business-dashboard.git
```

2. Masuk ke folder project:

```bash
cd weekly-business-dashboard
```

3. Jalankan file `index.html` menggunakan browser.

---

## Embed Tableau Dashboard

Dashboard Tableau di-embed menggunakan iframe berikut:

```html
<iframe 
  src="https://public.tableau.com/views/Dahsboard_LaporanBisnisMingguan/WeeklyBusinessPerformanceDashboard?:embed=y&:showVizHome=no&:display_count=n&:toolbar=no">
</iframe>
```
